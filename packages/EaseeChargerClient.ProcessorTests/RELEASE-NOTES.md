# EaseeChargerClient processor tests 0.1.0

Initial independent processor test package for EaseeChargerClient 1.0.0. Uses the published CrestronHomeNUnit 3.0.0 SDK and NUnit 5.0.0. The automatic suite contains 451 core cases; six selected read-only account/device checks are manual and require short-lived private access-only inputs. The charging-start test is excluded. This Utility package installs no production driver and requires shared pool admission and the processor workflow lease.
